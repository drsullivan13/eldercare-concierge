MASSACHUSETTS ZIP LOOKUP — SOURCE AND REUSE NOTES
Snapshot retrieved: November 11, 2026

OUTPUT
ma-zips.json contains 685 published Massachusetts ZIP records. Keys are five-character strings preserving leading zeros; values are {city,lat,lng}. No coordinates are invented, interpolated, hand-positioned or generated by an LLM.

539 coordinate pairs are copied from the 2026 U.S. Census ZIP Code Tabulation Area Gazetteer (INTPTLAT/INTPTLONG). These are published representative/internal points for 2020-based ZCTAs, not address coordinates and not guaranteed mathematical centroids. 146 ZIPs not found in that file retain their published GeoNames postal point. The companion ma-zips-provenance.json identifies the method for every ZIP; fallback points are approximate and many may be postal-only/special-purpose codes.

LIMITS
ZIP codes describe postal delivery, while ZCTAs are Census statistical areas; they are not interchangeable boundaries. This snapshot is not current USPS address/ZIP validity verification. ZIP points support approximate straight-line distance and coarse discovery; they do not establish drive time, service availability, actual family location, accessibility, provider licensure or suitability. Near a distance cutoff, confirm the actual address and service coverage.

PREFIX DETECTION
ma-zip-prefixes.json lists observed MA three-digit prefixes (010–027 plus 055). us-zip-prefix-states.json maps observed national prefixes to states. A non-MA prefix can be rejected as outside this Massachusetts dataset; an unlisted five-digit ZIP inside an MA prefix must be “unrecognized” rather than assigned a made-up coordinate. A Massachusetts prefix does not imply Boston-area service coverage. Define Greater Boston/North Shore/South Shore coverage separately using verified provider coverage and/or an explicit distance rule.

REBUILD
python /workspace/eldercare-poc-research/build_ma_zips.py --offline
Reuses retained source archives and produces byte-identical outputs. Use --refresh only to deliberately fetch a new snapshot. manifest.json records original URLs, byte counts and SHA-256 digests. A refresh can change records; review the diff before shipping. The script uses Python standard-library modules only.
