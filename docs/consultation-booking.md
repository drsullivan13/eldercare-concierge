# Connect a consultation scheduler

A signed-in family opens a North Jersey home-care agency, gives Harbor its callback details and a time window, and selects **Book**. The current account's verified email receives the invitation. Bookings and their current status also appear in the family plan. The browser practice lab continues to support fictional receptionist rehearsals.

For the first pilot, use [the six-office booking study](../research/north-jersey/consultations/booking-routes.md) to match the location, channel and type of consultation. Test the complete workflow with an office-owned test calendar or a designated test phone. Use the exact Harbor provider ID for each connection. Store each token in a private server environment variable.

1. Apply the SQL migrations in order: `supabase/consultation-bookings.sql`, `supabase/consultation-invites.sql`, `supabase/consultation-highlevel.sql`, `supabase/consultation-invites-highlevel.sql`, and `supabase/consultation-recovery.sql`. Set `SUPABASE_SECRET_KEY` for the same Supabase project as Harbor Auth. Each family can read its own receipts. Only the server writes provider confirmations.
2. For HighLevel, set `HARBOR_HIGHLEVEL_AGENCIES` to a JSON object keyed by Harbor provider ID. For Elderly Savior use `north-jersey-hp-hp0265900` with `calendarId: "QnvoAQkNH8HYRfrJk8Ri"`, the office’s authorized `locationId`, and `tokenEnv: "HARBOR_HIGHLEVEL_TOKEN_ORANGE"`. Configure a location token scoped to calendar, event and contact reads, event creation and contact creation. Set `inviteDelivery` to `agency` if the office sends invitations, or `harbor` when Harbor handles delivery. The publicly embedded calendar works before a private connection is configured.
3. For Calendly, set `HARBOR_CALENDLY_AGENCIES` to a JSON object keyed by Harbor provider ID. An entry contains `eventTypeUri`, `organizationUri`, and `tokenEnv`, naming a secret such as `HARBOR_CALENDLY_TOKEN_PILOT`. Use an agency-authorized free consultation event type. For a phone event, specify the matching `location` kind. Connect an event type that sends invitee confirmations and calendar invitations. Enable event type, availability and scheduled-event reads and invitee creation on the agency account.
4. For an office that books by phone, set `HARBOR_PHONE_AGENCIES` to a JSON map from each participating office ID to its verified US scheduling line. Set `TWILIO_ACCOUNT_SID`, `TWILIO_AUTH_TOKEN`, `HARBOR_BOOKING_FROM` (a voice-capable outbound number) and `HARBOR_BOOKING_ORIGIN` (the public HTTPS dashboard origin). Harbor calls the office, proposes a free 15-minute phone consultation, accepts another time within the authorized window, and reads back the time and callback number. The office must reserve the time and acknowledge it before Harbor issues the invitation.
5. For Harbor-sent calendar invitations set `RESEND_API_KEY` and `HARBOR_INVITE_FROM` (a bare address on a verified sending domain). An accepted send means the mail service accepted the message. The family can also download its calendar event from the portal. Adding it automatically to a specific Google account depends on that account's invitation settings.

After the dashboard is deployed, apply `supabase/enable-consultation-recovery.sql` to the Harbor production database. It schedules a check each minute and calls the dashboard only when a booking needs attention. The worker reads pending receipts and retries eligible email delivery after the browser closes.

Use a single test booking to verify the provider's attendee record, the family's saved receipt and the appointment in the test recipient's calendar. A failed phone connection has no appointment. If a provider accepted a request but the receipt was lost, check the existing request before submitting another. Appointment status describes the consultation only. The agency arranges staffing and care separately.

## Elderly Savior public-form pilot

From the signed-in office profile, choose **Book for me** and approve one availability window, the contact details and the office’s required contact terms. Harbor can book one free 30-minute Google Meet entirely inside that window. The worker checks the Eastern calendar by day and reopens the selected slot before submission. The optional promotional-text checkbox stays clear. The family can close the browser and see the result in **Your plan**.

Apply `supabase/public-form-bookings.sql` to the dashboard database. The authenticated user can authorize only their own job. Use a separate Postgres login with membership in `harbor_public_form_worker` for the worker. That role can read jobs and update progress, and cannot create approvals. The Vercel dashboard uses the signed-in Supabase session for this flow.

Run the worker on an awake host with Node 24, the locked development dependencies and Chromium. Supply `HARBOR_WORKER_DATABASE_URL` through the host’s secret store and configure the Supabase CA with `NODE_EXTRA_CA_CERTS` for verified TLS. Run `npm run worker:bookings` under a process supervisor. The Mac pilot uses LaunchAgent `com.harbor.public-form-worker`; inspect it with `launchctl print gui/$(id -u)/com.harbor.public-form-worker`. It resumes when the user logs in. A production deployment should monitor queue age and worker health on an always-on host.

A job moves to `submitting` durably before the one allowed final click. A lost response or interrupted submission stays uncertain. Confirm with the office before resolving a pending or unknown outcome. A human-verification prompt or changed terms stop the worker. The portal labels a consultation confirmed only when the office supplies matching confirmation evidence. This pilot implements the Elderly Savior calendar only.
